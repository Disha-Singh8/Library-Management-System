============================================================
 TROUBLESHOOTING
============================================================

Problem: Backend won't start
Solution: Port 5000 might be in use
  Windows: netstat -ano | findstr :5000
  Then kill the process or change PORT in server.js

Problem: Frontend won't connect to API
Solution:
  1. Check backend is running on port 5000
  2. Check browser console for errors
  3. Clear browser cache (Ctrl+Shift+R)

Problem: Login fails
Solution:
  1. Check demo users were created (database issue)
  2. Clear localStorage: F12 > Application > Local Storage > Clear All
  3. Restart both servers

Problem: Styling looks off
Solution:
  1. Hard refresh browser (Ctrl+Shift+R)
  2. Check main.css is loaded in Network tab
  3. Clear browser cache
